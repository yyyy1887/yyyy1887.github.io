⚙ GitHub 동기화 설정

GitHub 저장소의 Workd_data.md를 읽고 저장합니다. Fine-grained Personal Access Token은 해당 저장소의 Contents 권한(Read and write)만 부여하고, 본인만 사용하는 기기에서 입력하세요. 토큰은 이 브라우저 탭의 sessionStorage에만 보관됩니다.

중요: HTML에 비밀번호를 넣거나 공개 저장소에 토큰을 기록하지 마세요. GitHub Pages에 배포한 HTML은 누구나 소스 코드를 볼 수 있습니다. 로컬 잠금은 서버 인증이 아니며, 저장소가 공개라면 마크다운 내용도 공개됩니다.
